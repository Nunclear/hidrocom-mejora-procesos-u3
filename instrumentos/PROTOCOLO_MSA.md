# Protocolo propuesto de concordancia documental

## Alcance

Evaluar si los revisores aplican de manera consistente una regla previamente definida. Se propone un diseño de dos revisores para kappa de Cohen; no se afirma que existan personas ya asignadas o lecturas realizadas. Para otro número de revisores se elegirá un método adecuado y se documentará el cambio.

## Preparación y ejecución

1. Aprobar CTQ, categorías, excepciones, evidencia admisible y criterio de decisión. Distinguir «ilegible/no evaluable» de un incumplimiento.
2. Seleccionar casos autorizados que incluyan tipos y dificultades relevantes; registrar cómo se seleccionaron. No usar la etiqueta REVISAR como patrón oro.
3. Entregar copias identificadas con orden aleatorio a cada revisor. Realizar lecturas independientes y ciegas respecto de las respuestas del otro.
4. Registrar categoría, evidencia, revisor real, ronda y fecha. Si se estudia repetibilidad, repetir una ronda después del intervalo acordado sin consultar la lectura anterior.
5. Comparar acuerdo observado y matriz de contingencia; calcular kappa cuando sea definible. Reportar tamaño, prevalencias, marginales y casos no evaluables.
6. Resolver desacuerdos mediante cotejo autorizado y criterio aprobado; preservar las dos respuestas originales. La conciliación no debe sobrescribirlas.

## Cálculo e interpretación

Po = coincidencias / pares evaluables. Pe = suma de productos de proporciones marginales por categoría. Kappa = (Po−Pe)/(1−Pe). Si Pe = 1, kappa es no definido; no asignar 1 arbitrariamente.

Un umbral de aceptación debe acordarse; no adoptar una etiqueta universal como aprobación automática. Kappa describe concordancia, no exactitud frente a la realidad ni prueba causal. Datos simulados sirven solo para verificar el código. La conclusión del MSA queda pendiente hasta disponer de lecturas reales y originales autorizados.
